# 📊 Крипто дашборд

Современный дашборд для отслеживания криптовалют в реальном времени, построенный на React, TypeScript, React Query и Recharts.  
Проект ориентирован на масштабируемую архитектуру и производительный UI.

## ✨ Возможности

- 📈 Отслеживание криптовалют в реальном времени

- 🧩 Масштабируемая архитектура (FSD-подход)  

---

## 🏗 Архитектура

Проект построен по подходу, близкому к **Feature-Sliced Design (FSD)**:

````

src/
├── app/        # инициализация приложения
├── pages/      # страницы (Dashboard)
├── widgets/    # UI блоки (графики, таблицы)
├── entities/   # бизнес-сущности (монеты)
├── shared/     # переиспользуемая логика
│    ├── api/
│    ├── ui/
│    ├── hooks/
│    ├── util/
│    └── domain/
├── store/      # Redux store

````

---

## 🧠 Поток данных

- API запросы через `shared/api` (Axios)
- Кэширование через React Query
- Трансформация данных через adapters
- UI работает с нормализованными данными из entities слоя
